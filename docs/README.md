Personal Task Manager
is a web-based application designed to help Person organize their tasks efficiently.

Key functionalities:

1. Register, log in, and log out securely
2. Create tasks with a title and description
3. Set deadlines for tasks
4. Mark tasks as completed
5. Delete tasks
6. Dashboard highlights overdue and upcoming tasks to improve productivity

Technologies Used

1. Python (Flask framework)
2. MySQL (Database)
3. HTML5
4. CSS3
5. Git (Local version control)
6. WAMP Server (Apache + MySQL)

How to Run the Project

1. Start WAMP Server and ensure it is running (green)
2. Open a terminal in the project root folder
3. Install Python dependencies:

   bash
   pip install flask mysql-connector-python

4. Run the application:

   bash
   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000

Features of the system

Authentication (Register, Login, Logout, Session handling)
Task Management ( Add, Delete, Complete tasks)
Task Deadlines (Set deadlines with visual indicators for overdue, due today, or upcoming tasks)
